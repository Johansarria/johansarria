## 👋 Sobre Mí

Ingeniero de datos y desarrollador full-stack enfocado en **automatización, AIOps y agentes autónomos de IA** para el sector telecomunicaciones y e-commerce. Construyo pipelines ETL inteligentes, dashboards de monitoreo NOC/SaaS, herramientas de auditoría de infraestructura de red y agentes de IA que operan flujos de ventas y logística de punta a punta.

🔭 **Enfoque actual:** Automatización ISP, liquidación de infraestructura (postes/ductos), análisis predictivo de riesgos en redes de fibra óptica, y plataformas de comercio electrónico de alto rendimiento.
